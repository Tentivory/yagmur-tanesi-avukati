# Yağmur Tanesi Avukatı

> Islanan her vatandaş bir davacıdır.  
> Düşen her damla ise — bizim müvekkilimizdir.

Bu depo, gökyüzünün en küçük tüzel kişiliklerine ücretsiz, sürekli ve biraz da ıslak hukuki temsil sunar.  
Yazılım **gerçekten çalışır**. Mahkeme **gerçekten yok**. İkisi birden doğrudur.

## Kurulum

Python 3 yeter. Bağımlılık yok. Avukat zaten her şeyi yanında taşır.

```bash
git clone https://github.com/Tentivory/yagmur-tanesi-avukati.git
cd yagmur-tanesi-avukati
python3 avukat.py
```

## Ne yapar?

1. Rastgele bir yağmur tanesini müvekkil ilan eder.
2. Vatandaşın çorabına, pikniğine veya telefonuna dair bir isnat uydurur.
3. İki cümlelik, bilimsel görünen bir savunma okur.
4. Karar verir. Kararın yüzde yüzü rastgeledir; bu da emsal teşkil eder.

## Yasal uyarı

Bu yazılım meteoroloji, baro veya Anayasa Mahkemesi değildir.
Çatı aktığında dosya ıslanabilir. Temyiz hakkı buharlaşabilir.
